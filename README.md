# ういビーム検出器/ういビーム検出器 CLI

ういビーム検出器 および ういビーム検出器 CLI は，
テキストから縦読み，斜め読みを含むういビームを発見するためのライブラリとアプリケーションです．

## 開発環境
Microsoft Windows 11 Insider Preview (Future Platforms)<br>
Visual Studio 18<br>
.NET 10.0

## 使い方
ういビームを探索したい文字列をテキストファイルで保存し，
```
PS> ./uibf [ファイルパス]
```
のようにコマンドライン引数でテキストファイルへのパスを指定することでういビームを調べることができます．
また，uibf.exeをターミナルから叩くかダブルクリックして起動してからファイルパスを指定することも可能です．
